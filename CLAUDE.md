## Project Overview

Personal learning blog (blog.manas-mishra.com) built with **Astro + Starlight**, deployed on **Cloudflare Pages**.

## Commands

```bash
npm run dev        # Dev server at localhost:4321
npm run build      # Build to ./dist/
npm run preview    # Preview built site locally
```

Deploy is handled automatically by Cloudflare Pages on push. There is no test suite or linter configured.

## Architecture

### Content

All content is **MDX** with **YAML frontmatter** (`---` delimiters). Files live in `src/content/docs/` — Starlight's `docsLoader()` in `src/content.config.ts` picks them up.

- `src/content/docs/book_summaries/` — Book summary notes
- `src/content/docs/course_summaries/` — Course notes, can be deeply nested
- Each section directory has an `index.mdx`

Frontmatter fields of note: `title`, `sidebar.label` (sidebar label), `draft`, `sidebar.order` (ordering within a section).

### Astro Config (`astro.config.mjs`)

- **Starlight** integration manages the docs layout, sidebar (autogenerated from `book_summaries/` and `course_summaries/` directories), and component overrides
- **KaTeX**: `remark-math` + `rehype-katex` plugins, KaTeX CSS imported in `customCss`
- **Mermaid**: custom remark plugin (`src/plugins/remark-mermaid.js`) converts `mermaid` code fences to `<div class="mermaid">` blocks
- Output: `static` site, built to `./dist/` (configured in `wrangler.toml`)

### Custom Components (`src/components/`)

Used as MDX components or imported in `.mdx` files:

| Component | Purpose |
|---|---|
| `ShowImage.astro` | Lazy-loaded image from `src/assets/img/image-{name}` |
| `ListSubPages.astro` | Auto-generates child page list (ordered by `sidebar.order`) |
| `Define.astro` | Styled definition block (term + content slot) |
| `Collapse.astro` | `<details>`/`<summary>` collapsible section |
| `Figure.astro` | Figure with caption |
| `DownloadableLink.astro` | Styled download link |
| `DsaTable.astro` | DSA-specific table component |
| `MuReference.astro` | Reference link component |

Starlight component overrides live in `src/components/overrides/`:
- `Head.astro` — adds KaTeX CSS and any extra head tags
- `Footer.astro` — custom footer

### Styling

`src/styles/custom.css` — imports in Starlight `customCss`. Uses Starlight CSS variables (`--sl-color-accent`, `--sl-color-bg-sidebar`, etc.) for theming consistency.
